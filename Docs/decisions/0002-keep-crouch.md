# 0002. 앉기를 유지한다

- 상태: 채택
- 날짜: 2026-10-18

## 배경

기획서([GameDesign.md](../GameDesign.md) 4장)는 오버워치를 기준으로 이동을 "걷기, 점프, 앉기 없음"으로 적었다. 그런데 Lyra 기반이라 앉기(Left Ctrl 토글)가 이미 들어 있었고, 1인칭 기본 조작을 점검할 때 네트워크 복제까지 정상으로 동작했다. 오버워치에도 실제로는 앉기가 있다.

## 결정

앉기를 남긴다. 1인칭 리그와 회귀 검사도 앉은 상태(`crouch_dn85`, `walk_back_crouch_dn60`)를 포함한다.

달리기는 따로 넣지 않는다. 기획상 Shift는 스킬 1(Soldier 질주)이라 공통 달리기 키와 충돌한다.

## 대안

- **앉기 제거(기획서 그대로):** 이미 동작하는 기능을 빼는 비용만 있고 얻는 게 없다. 맵·스킬 설계에서 앉기를 쓸 여지도 사라진다.

## 결과

- 1인칭 계산이 앉기 자세에서도 맞아야 해서 검사 상태가 늘었다.
- 앉기 카메라 높이는 애니메이션이 정한다([0004](0004-full-body-first-person.md)).
- 기획서의 이동 항목도 이 결정에 맞춰 고쳤다.
