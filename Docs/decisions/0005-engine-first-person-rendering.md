# 0005. 뷰모델은 엔진 First Person Rendering 레이어로 그린다

- 상태: 채택
- 날짜: 2026-10-19

## 배경

총·팔은 시점에 고정돼 있고 몸·벽은 월드에 있다. 같은 깊이 버퍼에 그리면 제자리에서 몸을 돌릴 때(하체가 늦게 따라옴) 총구가 허벅지를 통과했고, 벽에 붙으면 총이 벽 속으로 들어갔다. 또 본인 3인칭 몸을 `OwnerNoSee`로 숨기면 그림자까지 사라졌다.

## 결정

UE 5.5부터 들어간 엔진 First Person Rendering을 쓴다.

- 1인칭 몸(팔·상체)과 로컬 총은 `FirstPersonPrimitiveType = FirstPerson`. 렌더링할 때만 카메라 쪽으로 `FirstPersonScale`(0.3)배 당겨 그린다. 실제 위치·소켓은 그대로라 판정에 영향이 없다.
- 다리는 같은 메시의 사본을 월드 레이어로 그린다. 다리는 벽 뒤에 가려지고, 총은 항상 다리 앞에 그려진다.
- 3인칭 몸은 `WorldSpaceRepresentation`: 본인에게는 안 보이고 그림자만 드리운다. 3인칭 총은 그림자도 끈다(그림자가 1인칭 총 위로 떨어져 총이 하나 더 보였다).
- Lyra 카메라가 엔진 기본 카메라처럼 1인칭 스케일·FOV를 뷰에 넘기도록 Lyra 코어를 3줄 고친다.

## 대안

- **뷰모델 전용 FOV·별도 패스·깊이 압축(예전 게임 방식):** 엔진이 이제 프리미티브 단위로 지원하므로 직접 만들 이유가 없다.
- **카메라 매니저 교체, 메시 스케일 직접 축소:** 판정·그림자·애니메이션이 함께 바뀐다.
- **`OwnerNoSee` + `bCastHiddenShadow`:** 스켈레탈 메시에는 숨긴 그림자가 나오지 않았다.

## 결과

- 벽·다리 통과가 사라지고 본인 그림자가 정확히 보인다. 다른 플레이어 화면에는 영향이 없다.
- 엔진 5.5 이상이 필요하다.
- 회귀 검사에 정적 항목을 넣었다: 총구 거리 × `FirstPersonScale` < 캡슐 반지름, 레이어 설정, 그림자 설정.
- 자세한 설정: [FirstPersonRig.md](../FirstPersonRig.md) 7장.
