# 0003. 양손 무기 잡기 모듈은 위치만 맞추고, 손 모양은 애니메이션에 맡긴다

- 상태: 채택
- 날짜: 2026-10-18

## 배경

1인칭에서 총을 화면에 고정하면 Lyra 3인칭 애니메이션의 손이 총과 맞지 않는다. 왼손이 총에서 수십 cm 떨어지거나, 3인칭 손 회전을 그대로 붙이면 팔뚝과 손 사이가 56° 꺾였다. 무기마다 잡는 자리도 다르다. 손 위치와 손 모양(손가락)을 한 코드에서 모두 다루면 무기를 추가할 때마다 손가락 값을 손으로 맞춰야 한다.

## 결정

양손 잡기를 무기별 데이터와 공용 코드로 나눈다.

- `UFpsWeaponGripProfile`(DataAsset, 예: `DA_Grip_Rifle`): 무기별 1인칭 배치(총 뼈의 시점 기준 위치·회전, 보조 손 회전 각도·피벗, 정조준 값).
- `UFpsWeaponGripComponent`: 무기 액터에 붙는 표식. 어떤 프로파일을 쓰는지 알려 준다.
- 모듈(`UFpsFirstPersonAnimInstance`, `UFpsFirstPersonWeaponComponent`)은 **위치 보정만** 한다. 총을 시점에 두고, 손목을 총에 붙이고, 팔꿈치·어깨를 풀어 팔이 닿게 한다.
- **손 모양**은 그립 포즈 애니메이션(지금은 3인칭 애니메이션의 대기 자세)이 담당한다. 손을 고정하는 순간의 손가락 로컬 트랜스폼을 캡처해 쓴다.

목표 구도는 일반 FPS 소총 뷰모델이다. 총은 화면 오른쪽 아래, 팔은 화면 하단에 조금만 보이고, 왼손은 핸드가드를 아래에서 받친다.

## 대안

- **손가락까지 코드(IK·손가락 커브)로 계산:** 무기마다 손가락 값을 맞춰야 하고, 애니메이터가 고칠 수 없다.
- **1인칭 전용 팔 메시와 무기별 팔 애니메이션(전통적인 뷰모델):** 그림자·다리가 3인칭 몸과 따로 놀고, 무기마다 애니메이션 세트가 필요하다. [0004](0004-full-body-first-person.md)의 풀바디 방향과도 맞지 않는다.

## 결과

- 새 무기는 프로파일 하나와 그립 포즈만 있으면 된다.
- 손가락 모양은 잠금 순간의 애니메이션 자세라서, 무기별로 더 자연스러운 쥐는 모양이 필요하면 그립 포즈 애니메이션을 따로 만들어야 한다.
