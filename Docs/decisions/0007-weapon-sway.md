# 0007. 총은 화면에 고정하되, 이동 중 몸의 움직임을 0.25배만 따라가게 한다

- 상태: 채택
- 날짜: 2026-10-27

## 배경

총을 화면에 완전히 고정하면 몸이 흔들리는 만큼을 팔이 전부 받아서, 걸을 때 팔꿈치가 꿈틀거렸다. 반대로 애니메이션의 몸 흔들림을 총에 그대로(1배) 옮기면 뒤로 걸을 때 총구가 좌우 19cm 흔들렸고, 제자리에서 앉거나 내려다보기만 해도 총이 화면에서 7cm 흘러갔다.

## 결정

총 위치 = 흔들림 × 고정 위치. 흔들림은 몸이 총을 들고 있는 방식의 변화에서 다음처럼 만든다.

- 느린 평균과의 차이만 쓴다(고역 통과). 오래 남는 차이는 화면 배치를 바꾸지 않는다.
- 최대 5cm·6°로 자르고 `WeaponFollowsBody` **0.25**배를 곱한다.
- 지면 속도에 비례한다(150cm/s에서 최대, 정지 시 0).
- 빠른 회전 중에는 끄고, 대신 회전 관성(100°/s당 1°, 최대 2°)을 준다.
- 정조준 중에는 흔들림과 회전 관성을 0.25배로 더 줄인다(`AimWeaponSwayScale`).
- 어깨 자리도 같은 흔들림으로 옮겨서, 팔과 총이 한 덩어리로 움직인다.

값은 처음 0.35에서 시작했고, 이동 중 팔 맞춤을 다시 조정하면서 0.25로 낮췄다. 회귀 검사를 통과하는 범위에서 골랐다.

## 대안

- **완전 고정(0):** 팔꿈치 꿈틀거림이 남는다.
- **애니메이션 그대로(1):** 총구가 크게 흔들려 조준이 어렵다.

## 결과

- 걸을 때 총이 살짝 흔들리고 팔 모양은 유지된다.
- 값은 `Config/DefaultGame.ini`의 `[/Script/FpsCoreRuntime.FpsFirstPersonSettings]`에서 바꾼다. 바꾸면 회귀 검사 전체를 다시 돌린다.
