# 0008. 걸을 때 오른손목 검사 실패는 알려진 제약으로 둔다

- 상태: 채택
- 날짜: 2026-10-20

## 배경

Lyra 이동 애니메이션은 총 뼈를 손 안에서 움직인다(뒤로 걸을 때 5~9cm). 그대로 쓰면 화면에 고정한 총 위에서 손이 미끄러진다. 그래서 대기 자세에서 손과 총의 관계를 캡처해 고정한다([0003](0003-grip-module-position-only.md)).

그 대가로 걷거나 빠르게 돌 때 오른손목이 3인칭 같은 프레임과 12~34° 다르다. 회귀 검사의 한계는 10°라서 `walk_fwd_dn85` 같은 이동 상태에서 FAIL이 난다.

## 결정

이 FAIL은 고치지 않고 알려진 제약으로 둔다. 다른 항목은 모두 통과해야 하고, 한계값은 느슨하게 바꾸지 않는다.

## 대안

- **팔꿈치 폴을 손목 일직선 쪽으로(주 손 1.0):** 손목 차이가 거의 줄지 않고, 아래를 볼 때 팔꿈치가 화면으로 올라왔다(-4.7cm, 한계 -8).
- **손 고정을 끄기:** 손이 총에서 미끄러지는 더 눈에 띄는 문제가 돌아온다.
- **한계값 완화:** 검사가 실제 증상을 못 잡게 된다.
- **1인칭 전용 이동 포즈:** 제대로 된 해결책이지만 애니메이션 작업이 필요하다. 나중으로 미룬다.

## 결과

- 16:9 화면에서 오른손은 거의 화면 밖이라 플레이 중에는 잘 보이지 않는다.
- 검사 결과를 볼 때 이 항목의 FAIL은 예상된 것으로 읽는다. 새로 생긴 FAIL과 헷갈리지 않도록 목록을 [FirstPersonRig.md](../FirstPersonRig.md) 9장에 둔다.
- 1인칭 전용 이동 포즈를 만들면 이 결정을 다시 본다.
