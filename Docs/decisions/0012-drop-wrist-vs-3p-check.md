# 0012. 손목 검사에서 3인칭 대비 비교를 뺀다

- 상태: 채택
- 날짜: 2026-10-30

## 배경

회귀 검사의 손목 항목은 왼손목 꺾임 절대값(≤ 30°)과 함께, 양손목이 3인칭 같은 프레임보다 얼마나 더 꺾였는지(≤ 10°)를 봤다. 그립을 대기 자세에서 잠그므로 걸을 때 오른손목이 3인칭과 16~25° 달라 `walk_back_dn60`, `walk_fwd_dn85`에서 항상 FAIL이 났고, 이를 알려진 제약으로 두었다([0008](0008-accept-walking-wrist-fail.md)).

기준은 1인칭 화면에서 자연스럽게 보이느냐이고, 1인칭이 3인칭과 크게 달라도 상관없다.

## 결정

손목 항목에서 3인칭 대비 비교를 빼고, 왼손목(보조 손) 꺾임 절대값 검사만 남긴다. 항목 이름은 `support wrist`로 바꾼다.

## 대안

- **0008처럼 FAIL을 알려진 제약으로 두기:** 검사가 항상 실패해 새로 생긴 FAIL과 구분하기 어렵다.
- **3인칭 대비 한계값 완화:** 기준이 1인칭 화면이 아니라 3인칭이라는 점은 그대로다.

## 결과

- Full 검사가 실패 없이 통과한다(2026-10-30, 119항목).
- 1인칭 오른손목 모양은 더 이상 숫자로 재지 않는다. 화면에서 부자연스러워 보이면 1인칭 기준 검사를 새로 추가한다.
